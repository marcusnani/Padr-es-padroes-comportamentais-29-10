TRABALHO - PADROES COMPORTAMENTAIS - CONTEXTO: CHAMADOS DE TI

1. Abra o projeto Java/Maven do professor.
2. Copie a pasta src/main/java/padroescomportamentais e src/test/java/padroescomportamentais para o projeto (preferencialmente em uma COPIA do projeto).
3. Mantenha JUnit 5 configurado como no projeto original.
4. Execute todos os testes JUnit.
5. Os diagramas .puml podem ser abertos em PlantUML e exportados para PNG.
6. Entregue os codigos, testes e diagramas.

Os codigos foram adaptados para o contexto de chamados, mantendo os mecanismos dos padroes originais. A integracao usa uma classe de orquestracao adicional.
